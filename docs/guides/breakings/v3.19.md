# V3.19
This release moves Discord.NET to the modern .NET sdk versions, dropping support for .NET Framework and older .NET versions, prior to .NET 8.

## Modal updates 
With the new release Discord.NET now supports new modal components. This breaking by nature changes involved a number of updates to the modal related entities and builders, most notably the `ModalBuilder` and `ModalComponentBuilder` classes. The base type for any `Components` collections was changed to `IMessageComponentBuilder` from `ActionRowBuilder`, since modals' supported top level components now include `Label` and `TextDisplay` component types, with `ActionRow` build deprecated in favor of `Label` superseeding the function of the action rows.
